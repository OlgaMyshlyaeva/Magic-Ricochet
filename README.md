# Magic-Ricochet
A fast-paced "Time Attack" game where you throw fireballs at skeletons. Accuracy and strategy are key as you manage your remaining time.

## Game Mechanics
* **Physics Ricochet:** Fireballs bounce off surfaces to hit multiple targets.
* **Time Management:** 
    * **Red Skeleton:** Adds +5 seconds to your timer.
    * **Black Skeleton:** Instantly triggers "Game Over".
* **Dynamic Timer:** Real-time countdown UI tracking player performance.
* **Score System:** Track how many skeletons you can clear before time runs out.

## Tech Stack
* **Engine:** Unity
* **Language:** C#
* **Physics:** Sphere colliders with physics materials for bouncing.
